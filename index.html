如何添加新的 MOF？

1. 把新的 .glb 文件上传到当前 GitHub 仓库。

2. 打开本页面的 index.html。

3. 在 MODELS 数组中新增一条记录：

{name: "UiO-66", file: "UiO66.glb", desc: "Zr-MOF", tip: "可观察 Zr 节点与孔结构"}

4. 提交更改后，网页会自动更新。

课堂使用建议

• 学生扫码进入页面后，可用手指旋转与缩放。

• 支持的手机可点击“在 AR 中查看”。

• 可围绕“金属节点—有机配体—孔道结构—潜在应用”进行讲解。
